# TANAMORI 分類テストデータ

TANAMORI（開発コード: `tanamori`）の自動分類・検索・追加学習用テストデータです。

- 分類数: 6
- 各分類のファイル数: 3
- 合計: 18ファイル
- 形式: TXT / Markdown / CSV
- 文字コード: UTF-8

`expected_labels.csv` に各ファイルの正解分類を記録しています。ファイル名だけでなく本文からも分類できるようにしつつ、顧客名と案件名が一部で重なるデータを含めています。

## 正解分類

1. 会計
2. 会議
3. 斎藤様（顧客1）
4. 鈴木様（顧客2）
5. ホームページ（案件1）
6. 修正依頼（案件2）

実在の人物・会社・金額とは関係のない架空データです。
